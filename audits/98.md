[Backend] BE-01: Khảo sát và lựa chọn công nghệ Backend: NestJS, TypeScript, PostgreSQL

## 🎯 Mục tiêu

Khảo sát, đánh giá và thống nhất Tech Stack chính thức cho hệ thống EVManager, làm cơ sở triển khai Frontend, Backend, Database và DevOps trong các giai đoạn tiếp theo.

Sau khi trao đổi với PM và BA, nhóm thống nhất sử dụng:

### Frontend

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Chart.js
- FullCalendar
- JavaScript `fetch()` để gọi REST API

### Backend

- Java 21 LTS
- Spring Boot
- Spring Web
- Spring Data JPA + Hibernate
- Flyway
- Jakarta Bean Validation
- Spring Security + JWT
- Springdoc OpenAPI/Swagger
- Maven
- JUnit 5 + Mockito + Spring Boot Test
- SLF4J + Logback

### Database & DevOps

- PostgreSQL
- Docker + Docker Compose
- GitHub Actions
- Git + GitHub
