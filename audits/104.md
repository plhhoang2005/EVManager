# [Backend] BE-07: Phát triển Module Auth: Đăng nhập và JWT



## 🎯 Mục tiêu

Phát triển Module Auth cho phép đăng nhập, kiểm tra mật khẩu bằng BCrypt và xác thực bằng JWT.

## 📋 Checklist công việc

* [x] Cấu hình Spring Security và JWT
* [x] Cấu hình BCrypt Password Encoder
* [x] Tạo Auth Controller và Auth Service
* [x] Xây dựng API `POST /api/v1/auth/login`
* [x] Kiểm tra username/email và mật khẩu
* [x] Sinh JWT Access Token sau khi đăng nhập thành công
* [x] Xác thực JWT từ Header `Authorization: Bearer <token>`
* [x] Xử lý đăng nhập sai và token không hợp lệ
* [x] Kiểm tra API đăng nhập bằng Postman

## 📦 Kết quả cần giao nộp

* [x] Module Auth trong `backend/`
* [x] API `POST /api/v1/auth/login`
* [x] BCrypt Password Encoder hoạt động
* [x] JWT Authentication hoạt động
* [x] JSON Response đăng nhập và lỗi đúng chuẩn
* [x] Pull Request vào `develop`

## 🛠 Tech Stack

* Java 21 LTS

* Spring Security
