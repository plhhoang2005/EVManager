[Backend] BE-08: Xây dựng RBAC phân quyền người dùng



## 🎯 Mục tiêu

Xây dựng cơ chế phân quyền người dùng theo vai trò (Role-Based Access Control - RBAC) bằng Spring Security.

## 📋 Checklist công việc

* [x] Cấu hình Role-based Authorization với Spring Security
* [x] Định nghĩa các Role của hệ thống
* [x] Đọc Role từ thông tin người dùng sau khi xác thực JWT
* [x] Phân quyền truy cập theo Role cho API
* [x] Trả về HTTP 403 Forbidden khi không đủ quyền
* [x] Áp dụng phân quyền mẫu cho API quản lý sảnh tiệc
* [x] Kiểm tra quyền truy cập bằng Postman

## 📦 Kết quả cần giao nộp

* [x] Cấu hình RBAC trong `backend/`
* [x] Role Authorization hoạt động với JWT
* [x] API được bảo vệ theo Role
* [x] Xử lý lỗi 403 đúng chuẩn JSON Response
* [x] Tài liệu phân quyền cho Frontend và QA
