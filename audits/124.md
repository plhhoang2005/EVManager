[Backend] BE-27: Thiết lập GitHub Actions Workflow: Tự động chạy Lint, Build và Unit Test (CI)

### 🎯 Mục tiêu


Thiết lập GitHub Actions CI Pipeline tự động chạy Lint, Build và Unit Test mỗi khi có Pull Request.





### 📋 Checklist công việc


- [ ] Tạo file workflow `.github/workflows/backend-ci.yml` kích hoạt khi có Push hoặc PR vào nhánh `develop`.


- [ ] Thiết lập môi trường Ubuntu, cài đặt Java 20, cache dependencies để tăng tốc độ chạy.


- [ ] Chạy các bước kiểm tra tự động: `Maven run lint` -> `mvn clean install` -> `Maven run test` -> `Maven run build`.


- [ ] Chặn việc merge Pull Request nếu Pipeline CI bị báo đỏ (Fail).





### 📦 Kết quả cần giao nộp (Deliverables)


- File cấu hình `.github/workflows/backend-ci.yml`.


- Badge trạng thái CI xanh mướt hiển thị trên file `README.md` của repo.
