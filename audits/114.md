[Backend] BE-17: Phát triển Module Services: API Quản lý danh mục gói dịch vụ tiệc cưới

### 🎯 Mục tiêu
Phát triển Module Services: API Quản lý danh mục các gói dịch vụ gia tăng tiệc cưới.

### 📋 Checklist công việc
- [ ] Tạo bảng `services` (MC, Ban nhạc, Hoa tươi, Tháp rượu, Pháo kim tuyến) kèm đơn giá và đơn vị tính.
- [ ] Viết API `GET /api/services`: Lấy danh sách dịch vụ đang hoạt động phục vụ màn hình chọn dịch vụ.
- [ ] Viết API `POST /api/services`: Thêm mới gói dịch vụ tùy chọn.
- [ ] Viết API `PATCH /api/services/:id`: Cập nhật đơn giá hoặc trạng thái tạm ngừng cung cấp dịch vụ.

- Tích hợp API với màn hình chọn dịch vụ của Frontend.
