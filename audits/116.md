[Backend] BE-19: Xây dựng State Machine quản lý vòng đời hợp đồng (Draft -> Confirmed -> Completed)

### 🎯 Mục tiêu

Xây dựng State Machine quản lý nghiêm ngặt vòng đời của Hợp đồng tiệc cưới (Contract Lifecycle).



### 📋 Checklist công việc

- [ ] Định nghĩa enum ContractStatus: `DRAFT` (Bản thảo) -> `PENDING_APPROVAL` (Chờ duyệt chiết khấu >10%) -> `PENDING_DEPOSIT` (Chờ cọc) -> `CONFIRMED` (Đã cọc) -> `IN_PROGRESS` (Đang tổ chức) -> `COMPLETED` (Đã thanh lý) -> `CANCELLED` (Đã hủy).

- [ ] Viết logic kiểm tra điều kiện chuyển trạng thái: Chỉ được chuyển sang `CONFIRMED` khi số tiền cọc (depositAmount) đạt đúng 30% tổng giá trị (Total Amount).

- [ ] Chặn cập nhật thực đơn hoặc số bàn đối với hợp đồng đã ở trạng thái `COMPLETED` hoặc `CANCELLED`.

- [ ] Tự động giải phóng sảnh tiệc khi hợp đồng bị chuyển sang trạng thái `CANCELLED`.
