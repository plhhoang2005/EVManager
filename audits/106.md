[Backend] BE-09: Phát triển Module Users



## 🎯 Mục tiêu

Phát triển Module Users để quản lý tài khoản nhân viên, đổi mật khẩu và khóa/mở khóa tài khoản.

## 📋 Checklist công việc

* [x] Xây dựng Entity và Repository cho User
* [x] Xây dựng API lấy danh sách User có phân trang và lọc theo Role
* [x] Xây dựng API tạo User mới
* [x] Băm mật khẩu bằng BCrypt khi tạo hoặc cập nhật mật khẩu
* [x] Xây dựng API khóa/mở khóa tài khoản
* [x] Xây dựng API đổi mật khẩu cá nhân
* [x] Kiểm tra quyền truy cập bằng Spring Security
* [x] Viết unit test cho xử lý mật khẩu và đổi mật khẩu
* [x] Kiểm tra các API bằng Postman

## 📦 Kết quả cần giao nộp

* [x] CRUD User hoạt động
