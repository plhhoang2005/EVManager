[Backend] BE-20: Phát triển Module Payments: API Ghi nhận tiền đặt cọc đợt 1 và thanh toán đợt 2

### 🎯 Mục tiêu
Phát triển Module Payments: API Ghi nhận đặt cọc đợt 1 và quyết toán đợt 2 của hợp đồng.

### 📋 Checklist công việc
- [ ] Tạo bảng `payments`: contractId, amount, paymentDate, paymentMethod (CASH, BANK_TRANSFER, POS), paymentType (DEPOSIT, FINAL), notes.
- [ ] Viết API `POST /api/payments`: Ghi nhận giao dịch nộp tiền, tự động cập nhật số tiền đã trả và công nợ còn lại trong bảng contracts. Lưu ý: Phải phân biệt rõ ràng contract.depositAmount (số tiền cọc cần đóng) với payment records (các giao dịch thực tế).
- [ ] Viết API `GET /api/contracts/:id/payments`: Lấy lịch sử toàn bộ các lần thanh toán của một hợp đồng.
- [ ] Chặn ghi nhận thanh toán vượt quá tổng giá trị hợp đồng cần thu.

### 📦 Kết quả cần giao nộp (Deliverables)
- Mã nguồn: `backend/src/payments/` controller và service.
- Kiểm tra đồng bộ số dư công nợ sau mỗi lần nạp tiền.
