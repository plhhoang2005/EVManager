# [Backend] BE-02: Thiết kế kiến trúc Modular Backend theo chuẩn Clean Architecture

## 🎯 Mục tiêu

Thiết kế kiến trúc Backend cho EVManager sử dụng **Java 21 + Spring Boot**, theo hướng Modular Architecture và Clean Architecture.

## 📋 Checklist công việc

- [x] Phân chia các module: Auth, Users, Customers, Venues, Events, Contracts, Payments, Reports.
- [x] Thiết kế kiến trúc Layer: Controller → Service / Use Case → Repository → Spring Data JPA → PostgreSQL.
- [x] Chuẩn hóa RESTful API với prefix `/api/v1` và endpoint dạng số nhiều.
- [x] Chuẩn hóa HTTP Status Code: 200, 201, 400, 401, 403, 404, 409, 500.
- [x] Thiết kế cấu trúc thư mục Backend phù hợp với Spring Boot.
- [x] Định hướng Validation và Exception Handling.
- [x] Định hướng Authentication/Authorization bằng Spring Security + JWT.

## 📦 Kết quả cần giao nộp

- [x] Tạo tài liệu `docs/design/backend-architecture.md`.
- [x] Tạo sơ đồ kiến trúc Backend.
- [x] Tạo sơ đồ các module để cả nhóm tham khảo.

## 🛠 Tech Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA + Hibernate
- PostgreSQL
- Flyway
- Spring Security + JWT
- Maven
