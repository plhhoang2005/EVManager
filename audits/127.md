[Backend] BE-30: Triển khai Backend API lên môi trường Staging/Cloud phục vụ kiểm thử UAT

### 🎯 Mục tiêu


Triển khai Backend API và Database PostgreSQL lên hạ tầng Cloud (Render / Railway / VPS) phục vụ kiểm thử UAT.





### 📋 Checklist công việc


- [ ] Tạo cơ sở dữ liệu PostgreSQL Managed Database trên Cloud (Supabase hoặc Neon).


- [ ] Chạy lệnh `mvn flyway:migrate` để đồng bộ toàn bộ cấu trúc bảng lên database cloud.


- [ ] Nạp dữ liệu mẫu (Seed Data) lên môi trường cloud bằng lệnh `Java/Spring Data seeding (hoặc Flyway callbacks)`.


- [ ] Deploy ứng dụng Spring Boot lên Render/Railway, cấu hình đầy đủ các biến môi trường Production.


- [ ] Kiểm tra endpoint Health Check `GET /api/health` trả về `{ status: 'ok' }` với tên miền HTTPS công khai.





### 📦 Kết quả cần giao nộp (Deliverables)


- Đường link API Staging công khai (VD: `https://evmanager-api.onrender.com/api`).


- Bàn giao link API cho Frontend và QA kiểm thử UAT.
