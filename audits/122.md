[Backend] BE-25: Xây dựng Service xuất dữ liệu hợp đồng tiệc cưới ra định dạng PDF

### 🎯 Mục tiêu
Xây dựng Service xuất dữ liệu hợp đồng tiệc cưới và phiếu thu ra file PDF bằng PDFKit / Puppeteer.

### 📋 Checklist công việc
- [ ] Cài đặt thư viện `pdfmake` hoặc `puppeteer` để chuyển đổi HTML template thành file PDF.
- [ ] Thiết kế mẫu PDF chuẩn văn bản pháp lý: Logo trung tâm, hoa văn trang trí, bảng kê chi phí, điều khoản hợp đồng.
- [ ] Hỗ trợ gõ tiếng Việt có dấu hoàn hảo không bị lỗi font chữ (sử dụng font Roboto / Times New Roman nhúng base64).
- [ ] Viết API `GET /api/contracts/:id/pdf`: Tải file hợp đồng PDF về máy.

### 📦 Kết quả cần giao nộp (Deliverables)
- Mã nguồn: `backend/src/reports/pdf-export.service.java`.
- File mẫu PDF xuất ra lưu tại `docs/design/sample-contract.pdf`.
