[Backend] BE-18: Phát triển Module Contracts: API Tạo đơn đặt tiệc, tính chi phí và chiết khấu

### 🎯 Mục tiêu
Phát triển Module Contracts: API Tạo đơn đặt tiệc, tính toán tổng chi phí và sinh mã hợp đồng tự động.

### 📋 Checklist công việc
- [ ] Viết DTO `CreateContractDto` nhận: customerId, venueId, eventDate, shift, menus: [{menuId, tableCount}], serviceIds, discountPercent.
- [ ] Tự động tính toán chi phí (dùng BigDecimal): Menu Amount = Σ(Menu Price × Table Count); Service Amount = Σ(Service Price × Qty); SubTotal = Menu Amount + Service Amount; Discount = SubTotal × Discount%; Taxable = SubTotal - Discount; VAT = Taxable × VAT%; Total = Taxable + VAT; Deposit = Total × 30%.
- [ ] Tính toán bàn sơ cua: Bàn sơ cua = FLOOR(Tổng số bàn đặt / 10). Bàn sơ cua tuyệt đối không tính tiền lúc lập báo giá/hợp đồng.
- [ ] Phân luồng phê duyệt: Nếu discountPercent > 10%, trạng thái khởi tạo phải là PENDING_APPROVAL.
- [ ] Tự động sinh mã hợp đồng duy nhất theo quy tắc: `HD-YYYYMMDD-STT` (VD: `HD-20261010-001`).
- [ ] Trước khi tạo hợp đồng, gọi Conflict Checker để khóa giữ sảnh tiệc tức thì.

### 📦 Kết quả cần giao nộp (Deliverables)
- Mã nguồn: `backend/src/contracts/` controller và service.
- Kiểm tra tính toán tiền chính xác tuyệt đối không bị lỗi làm tròn số.
