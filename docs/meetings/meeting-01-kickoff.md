## 4. Quy ước làm việc

**Git Workflow:**
- Branch: main → develop → feature/<ten-chuc-nang>, fix/<ten-loi>, docs/<noi-dung>
- Không push trực tiếp lên main hoặc develop
- PR cần ít nhất 1 người review trước khi merge

**Commit Convention:**
- feat: thêm chức năng mới
- fix: sửa lỗi
- docs: cập nhật tài liệu
- test: thêm/sửa test case
- chore: cấu hình, setup

**Kênh liên lạc:**
- Kênh chính: ________________
- Họp nhóm: ________________
- Quản lý task: GitHub Issues + Project Board

**Lịch họp hằng tuần:**
- Đầu tuần: Planning (mục tiêu, task, deadline)
- Giữa tuần: Sync ngắn (kiểm tra blocker)
- Cuối tuần: Demo nội bộ + review + cập nhật timesheet
